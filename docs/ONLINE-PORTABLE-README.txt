TARKOV WORKBENCH 1.8.5 - ONLINE SETUP EDITION
Author: CA

Keep this whole folder together. Start Tarkov-Workbench.exe in this folder.
The first launch asks before downloading any game data or item images.

Choose Download data to retrieve the current community export from
json.tarkov.dev and the required item images from assets.tarkov.dev.
The app checks the download and saves it in the Windows user profile
(AppData/Roaming/Tarkov Workbench) for later offline use.
If you choose Stay offline, nothing is downloaded and the builder remains
empty. Open Update database when you are ready to set it up.

After setup, Update database checks for newer data only when you ask.
It downloads new or changed images; unchanged local images are reused.
A failed or cancelled download leaves your last saved database intact.
The source is maintained by the Tarkov community and can lag behind EFT.

This ZIP contains no Escape from Tarkov item images or database snapshot.
It requires an internet connection for first setup. There is no browser,
account, installer or background update. Keep all DLLs and folders beside
the EXE. This edition is unsigned and Windows may block unfamiliar apps.
